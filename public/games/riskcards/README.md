# Assumindo o Risco risk cards

Card battler local para `track-11`, criado para o psicoZ.

- O jogador começa cada assalto com três cartas.
- Cada carta posicionada invoca uma tropa com quantidade de soldados.
- Três lanes resolvem combate contra ondas inimigas.
- Tema ficcional do álbum: dealer, smoker, crackhead, gunman e outras figuras como arquétipos sombrios de rua, sem assets externos.
- Vitória real: vencer três assaltos por posicionamento e resolução de combate.
- Progresso reportado somente via `PsicoZ.report`.
