# PsicoZ red terraria

Sandbox lateral local para `track-09`, criado para substituir Asteroids por uma releitura compacta de Terraria na estética psicoZ.

- Mundo de blocos em Canvas, com terra, pedra, minério vermelho e sigilos.
- Movimento lateral, pulo, mineração e colocação de blocos.
- Vitória real: coletar minério vermelho e acender cinco sigilos.
- Sem assets externos e sem armazenamento próprio.
